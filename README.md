# Pokémon Data Pipeline

Este projeto consome dados da PokeAPI, processa e gera insights.

## Configuração

1. Clone o repositório:
```bash
git clone https://github.com/bbiancalopess/pokeapi-pipeline.git

cd pokeapi-pipeline
```

2. Garanta que você tenha python e pip instalados. Você pode fazer isso tentando verificar a versão do python e do pip da sua máquina com os comandos
```bash
python --version

pip --version
```

3. Instale as dependências:
```bash
pip install -r requirements.txt
```

4. Execute o script:
```bash
python main.py
```

Os resultados estarão na pasta data/.
